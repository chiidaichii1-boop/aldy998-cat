`main.py` (Python stdlib only) writes one cat joke to `/output/entry.txt`:

> My cat ignores me all day, then at 3am walks across my face like a landlord doing an inspection.

96 characters, inside the 1–200 gate. Deterministic: two runs produce byte-identical output.
